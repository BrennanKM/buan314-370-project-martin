# 002 · Part 2 · Search: sportsbook results by bet type (parlays against single bets)

Launched 2026-11-23 by the lead agent. Subagent type: general-purpose (web research, read only). Adapts course Prompt 2.1 (search for candidate data sets).

## Context
A business analytics student is choosing a course project topic. One candidate question is: "How much more do bettors lose per $100 wagered on parlays than on single bets, by sport and sportsbook?" The decision-maker is a person who bets. The ideal data set has one row per sportsbook (or operator) per month per sport or bet type, covers a US state since legal online betting began there, and includes dollars wagered (handle) and sportsbook revenue (so the share kept, the "hold", can be computed), plus categories such as operator, sport, bet type (parlay or not), and online or retail. The course requires roughly 500 rows or more, at least three numeric variables and at least two categorical variables (one with two categories or reducible to two), public and free data from the original publisher, in table form (CSV or Excel preferred; PDF-only is a serious weakness), with some documentation of what the columns mean.

## Ask
Search the web for publicly downloadable data sets from US state gaming regulators (or other primary publishers) that report sports betting handle and revenue broken out by bet type (parlay versus straight or single) and/or by sport, ideally also by operator. Leads to check first: the Illinois Gaming Board sports wagering reports, the Colorado Division of Gaming monthly sports betting proceeds reports, and any other state that publishes parlay or sport breakdowns (for example Indiana, Iowa, New Jersey, Maryland, Massachusetts, Oregon). Give up to six candidates in a table: name · original publisher · address of the page you opened · file format (CSV, XLSX, PDF, web table) · approximate rows and columns (or "not stated") · what one row is · period covered · whether results are broken out by operator, by sport, by parlay or not · license or terms of use · whether a data dictionary or definitions page exists. Then rank them for the question above and say in one line what each lacks.

## Constraints
- List only sources you found and opened in this search, with the address you opened. Write "not stated" wherever the page does not give a row count or a license; do not estimate. Prefer the original publisher; if you find a re-upload or an industry tracker, trace it to the regulator and list that instead.
- Exclude simulated or synthetic data and paid data products.
- Read only. Do not create accounts, sign in, accept terms, submit forms or download large files. Do not write or edit any files on this computer; return your findings in your final message.
- If a site blocks you, say so and name the page.

## Verify
For each candidate, give the title and publisher name a person should see when they open the link, so the student can confirm the page exists and matches your description. State plainly, for the best candidate, whether a file with operator-by-month-by-bet-type rows can actually be downloaded in table form, and how you know.
