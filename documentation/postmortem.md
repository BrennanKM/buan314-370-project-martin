## 2. Six short answers (about 500 to 800 words in all)

1. Where was the assistant the strongest partner, and what about that task made it so?

2. Where did it leave the most to be desired, and what did that cost you: time, a wrong turn, an error that nearly reached a report?

3. Describe one mistake by the assistant that you caught, and how you caught it. Then describe one you nearly missed.

4. Show one prompt from early in the project and one from late, for similar tasks. What changed in how you ask?

5. Which part of this project could you now do without an assistant? Which part could you not?

6. In three sentences, what would you tell a student starting this project next term?
